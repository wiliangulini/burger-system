# Workspace de agentes

Este diretório é a base local e versionável para futuros documentos e artefatos controlados do roadmap de IA.

## Estado na IA-01

- O diretório é apenas documental e inerte.
- O único conteúdo previsto nesta etapa é este `README.md`.
- Nenhum agente real, automação, integração ou workflow é criado ou executado aqui.
- As subpastas operacionais futuras não são criadas nesta etapa.

## Fronteira de uso

Conteúdo permitido:

- documentação local autorizada pela etapa vigente;
- material fictício ou anonimizado, quando uma etapa futura o autorizar;
- arquivos explicitamente previstos pelo roadmap e submetidos a revisão.

Conteúdo proibido:

- `.env`, tokens, secrets, credenciais, certificados ou chaves;
- dados pessoais reais, conversas reais ou logs sensíveis;
- scripts, binários, comandos, hooks, skills ou workflows executáveis;
- configurações de agentes reais;
- arquivos destinados a publicação, envio, campanha ou integração externa real;
- artefatos de produção.

Qualquer identificação de conteúdo proibido bloqueia a etapa. O conteúdo sensível não deve ser aberto, copiado, impresso ou registrado no relatório.

## Convenções

- Usar caminhos relativos à raiz do repositório.
- Preservar os nomes previstos na etapa e no roadmap.
- Identificar documentos de etapa pelo respectivo código `IA-XX` quando aplicável.
- Não criar novas pastas ou estados de fluxo sem autorização da etapa correspondente.

Detalhes das futuras pastas operacionais e de suas transições: Não especificado no roadmap.

## Controle e rollback

O Git fornece rastreabilidade para os artefatos autorizados. Commit, push, merge, deploy e ações externas não fazem parte da IA-01. O rollback deve se limitar às alterações desta etapa e não deve apagar evidências necessárias para eventual auditoria.
