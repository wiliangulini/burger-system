# legacy-code-audit — burger-shop-system

## Finalidade

Descobrir o comportamento real de uma base existente antes de planejar nova
etapa. A auditoria é somente leitura e não pressupõe que documentação anterior
esteja correta.

## Procedimento

1. Confirme branch, status e histórico relevante.
2. Mapeie entrypoints, módulos, contratos, dados e consumidores.
3. Compare documentação, testes e comportamento implementado.
4. Identifique código órfão, duplicações, acoplamentos e riscos de regressão.
5. Separe fatos comprovados, hipóteses e lacunas sem evidência.
6. Recomende baseline e sequência segura de modernização.

## Saída

Forneça inventário da base, fluxos atuais, divergências documentais, riscos
classificados e pré-condições para a próxima implementação.
