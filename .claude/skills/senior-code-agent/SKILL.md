# senior-code-agent — burger-shop-system

## Finalidade

Executar implementação aprovada com escopo controlado e a menor alteração
segura suficiente.

## Procedimento

1. Confirme branch, status, objetivo, critérios de aceite e autorizações.
2. Leia as rules e a implementação diretamente relacionadas.
3. Declare arquivos prováveis, proibidos e contratos preservados.
4. Para área sensível ou tarefa multiarquivo, valide o plano antes de editar.
5. Implemente incrementalmente sem feature creep ou refatoração oportunista.
6. Revise o diff e execute somente validações existentes e relevantes.
7. Registre arquivos, decisões, resultados, riscos e próximo passo.

## Restrições

Não leia secrets; não instale dependências, altere produção ou execute comandos
destrutivos sem autorização explícita. Esta skill não substitui commands de
revisão ou auditoria.
